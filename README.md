# Weather forecast

Installable web app (PWA): today's and tomorrow's weather for any city or any place on the world map.

Open https://Jonas511329.github.io/weather-forecast/ on an Android phone in Chrome and choose **Install app** (or menu > *Add to Home screen*).

Data: [Open-Meteo](https://open-meteo.com/) (weather, place search), [OpenStreetMap](https://www.openstreetmap.org/copyright) (map tiles, Nominatim place names).
